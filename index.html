Perplexity's new Monitor API turns web search from a one-off query into a nonstop watchdog

Perplexityの新「Monitor API」が変える、ウェブ検索の常時監視システム

  • Perplexityが発表した「Monitor API」は、スケジュール設定に基づいてウェブを継続的に検索し、関連する変更をWebhook経由でAIエージェントに直接通知するサービスである。
  • APIには、指定した検索クエリの最新動向を追う「ウェブモニター」と、価格ページや変更履歴などの特定ページを追跡して差分を検出する「ページモニター」の2つのモードが用意されている。
  • 独自開発の決定モデルが開発者の定義した目標に基づき、検索結果やページの変更点に対して関連性、信頼性、新規性、適時性などのフィルターをかけ、重要な情報のみを送信する。
  • 従来の開発手法のように自前で定期検索や重複削除、変更検知のコードを維持する必要がなくなり、数百ものトピックを効率的に監視できる。
  • すでに利用可能となっており、料金は1,000リクエストあたり1ドルで提供されている。

AI is getting better faster than experts can reliably test whether new systems are safe, METR warns

AIモデルの急速な進化スピードに専門家による安全性テストが追いついておらず、破滅的なリスクへの対応が困難になる恐れがあると、AI研究組織METRが警告しています。

  • AIモデルはAI研究タスクにおいて急速に向上しており、現在の公開データだけでは今後数年間の劇的な加速を否定できない状況にある。
  • 明確に定義されたコーディングや計算タスクではすでに大半の時間で経験豊富な人間のプロフェッショナルを凌駕しており、処理可能なタスクの長さは3.6か月ごとに倍増している。
  • 単純な外挿データによると、AIは200時間かかる最長タスクにおいても、2027年7月までに50%の成功率に達する予測となっている。
  • 一方で、即座のフィードバックがなく実際の判断力を要するオープンな質問や、訓練環境の再現が難しい状況では依然として苦戦している。
  • 開発者が類似したテスト環境で訓練を行うため、一般的に行われる簡易的なテストでは実世界でのパフォーマンスが過大評価される可能性があると指摘されている。

Security researchers show how cheap AI inference providers steal keys and snoop on users

安価なAI推論プロバイダーや仲介業者における深刻なセキュリティ上の脆弱性と、ユーザーデータの盗難リスクが露呈した。

  • セキュリティ企業Dragosの調査により、安価なAIサービスにおいて攻撃者が認証情報やAPIキーを盗み見ていることが判明した。
  • 約200万件のテストリクエストを用いた検証の結果、侵害されたプロバイダーでは、ユーザーのAWSキーなどが数ヶ月にわたり検出されずに窃取されていた。
  • マーケットプレイスの仲介業者は、モデルを最安値で出品してログを有効にするだけで、脆弱性を突くことなく顧客のリクエストを傍受していた。
  • 「ゼロデータ retention（ZDR）」などのプライバシー設定が頻繁に無視され、米国のプロバイダーを経由した場合でも中国のAIラボなどが秘密のテストURLにアクセスしていた。
  • 窃取された情報が不正アクセスの試行に悪用される事例や、主要な米国のプロバイダーが自社のポリシーに反して長期間テストURLをクロールし続ける問題も確認された。

Lean and Mathlib community officially confirms Levent Alpöge's proof of the Riemann hypothesis is correct

リーマン予想の証明が正しいことの確認について

  • スタンフォード大学の数学者レヴェント・アルポゲ氏が発表したリーマン予想の証明が、定理証明支援系「Lean」およびMathlibコミュニティによって正式に正しいと確認された。
  • 証明は1,700万行のLeanのコードとして書かれ、複数の人々による独立した検証で同じ結果が得られたため、コミュニティは完全な信頼を表明している。
  • リーマン予想は素数の分布に関する数学界の最も有名な未解決問題の一つであったが、Metaculusの予測や専門家の予想よりも大幅に早い段階で解決に至った。

GPT-6.2 Astra and Sol get to the point faster but score lower on transparency than Claude

OpenAIの新モデル「GPT-6.2 Astra」と「Sol」のコミュニケーションスタイルの変化とAnthropicの「Claude」との比較

  • OpenAIのGPT-6.2 AstraとSolは、前モデルに比べて回答が34〜40%短くなり、質問に直接的かつ迅速に答えるようになった。
  • 両モデルとも回答の構造化が減り、見出しやダッシュの使用量が大幅に減少した一方で、「答えファースト」や自然な表現のスコアは向上した。
  • 不確実性を認める頻度が急減しており、Astraの該当スコアは96から24へ、Solは98から51へと低下し、Claudeと比較して透明性や構造の面で低い評価となった。
  • Claude（Fable 5.2やOpus 5.5）と比較して、AstraとSolは構造と透明性のスコアが低く、特にOpus 5.5は全モデルの中で最も高い情報量スコアを記録している。

Nvidia researchers argue huge AI context windows are a dead end

Nvidiaの研究者が巨大なAIコンテキストウィンドウは行き止まりであると主張

  • 近年、AIのコンテキストウィンドウは急速に拡大し、モデル全体で小説一冊分をも一度に処理できるようになっているが、Nvidiaの研究チームは、これは多くの場合において過剰であり、コストがかかると指摘している。
  • 多くのテストにおいて、巨大なコンテキストを一度に読み込ませるよりも、定期的な要約とターゲットを絞った情報の検索を組み合わせた手法の方が、同等にうまく機能することが示されている。
  • コンテキストウィンドウの拡大はAIの作業記憶を飛躍的に向上させたが、すべての情報を一度に保持・処理する方法は効率性の面で限界があり、別のアプローチの必要性が浮き彫りになっている。

Muru：AI支援によるRust製のPythonアプリ向けサーバー開発

  • 「mod_wsgi」の作者であるグレアム・ダムプレトン氏が、ASGIおよびWSGIのPythonアプリケーション向けに、AI支援を活用して開発している新しいRust製サーバー「Muru」を発表した。

  • 作者はAIを活用しつつも、mod_wsgiで培った20年間の経験を活かして品質の取捨選択を行い、信頼できるツールに仕上げるための地道な努力を続けている。
